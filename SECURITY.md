# Security Policy

## Supported versions

Only the latest release on the `main` branch of Arcade-Game-Center receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Email **zoltan.dul@gmail.com** with a description, steps to reproduce and the affected
version or commit. You will get an answer within 7 days.

The portal talks to a small PHP leaderboard API (`arcade-api/`); reports about score submission, rate limiting or input validation are especially welcome.
