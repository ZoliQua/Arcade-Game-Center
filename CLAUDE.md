# Arcade-Game-Center — CLAUDE.md

## Project facts

- **Repository**: https://github.com/ZoliQua/Arcade-Game-Center — npm workspaces monorepo, React 18 + Vite 5 + TypeScript 5.
- **Games** (each also a standalone sibling repo in `../`): tetris, snake, 2048, pacman, gomoku, tictactoe,
  breakout, invaders, connect4.
- **Communication**: answer the user in **Hungarian**; code, comments and docs are in English.
- **Scripts**: `npm run dev` · `dev:game @arcade/<id>` · `build` · `lint` · `typecheck` · `test` · `check` ·
  `sync:kit` · `sync:pull -- <id>` · `sync:push -- <id>` · `sync:check`.

## Architecture rules

- `packages/kit/src` is the single source of the shared runtime. It is vendored into every game as `src/arcade/`
  (in `apps/<id>/` **and** in the standalone repos). Never edit a vendored copy; edit the kit, run `npm run sync:kit`,
  and commit the copy in every game repo.
- `apps/<id>/` mirrors the standalone repo (`src/`, `index.html`, `public/`, `vite.config.ts`). Change one side, then
  `sync:push`/`sync:pull` and `sync:check`. `apps/<id>/package.json` + `tsconfig.json` are generated by
  `scripts/write-app-manifests.mjs`.
- Game contract: `<XxxGame embedded onGameOver onRunEnd onStatusChange />` + `<XxxDemo active />`; scoring only through
  `useArcadeRun`; saves only through `useSessionAutosave`/`useRestoredSession`; hotkeys start with `shouldIgnoreKey`.
- Shared community files come from `scripts/repo-docs.mjs` — do not hand-edit them in one repo only.
- The live `arcade-api/_config.php` is not in git; new games need a `max_score` entry there.

## Verification

Before claiming done: `npm run check` (lint → typecheck → test → sync:check → build) and, for UI changes, look at the
portal in a browser (`npm run dev`). Report what ran and what did not.
